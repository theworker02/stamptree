# stamptree

Stamp validation gates for tree inputs before they hit prod.

**Site:** https://theworker02.github.io/stamptree/

## Install / run

```bash
git clone https://github.com/theworker02/stamptree.git
cd stamptree
node src/cli.js
node --test
```
